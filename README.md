# 🚢 shipsSurvivors

A top-down survivorslike developed in **Godot** by Aztec Game Lab – Team 8 for Game Jam 2026.

## About

Pilot a ship across an open ocean while enemies continuously close in. Weapons attack automatically, defeated enemies provide experience, and leveling up allows the player to choose upgrades that improve the ship throughout the run.

## Current Status

In development for Game Jam 2026.

## Core Gameplay

- WASD / arrow-key movement
- Enemies spawn and pursue the player
- Automatic weapons
- XP and leveling
- Three-option upgrade selection
- Increasing difficulty
- Game over and restart

Godot
