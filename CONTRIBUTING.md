# Contributing to shipsSurvivors

## Before Starting Work

1. Find or create an Issue for the task.
2. Assign yourself to the Issue.
3. Move the Issue to `In Progress` on the project board.
4. Create a branch for your work.

Example branch names:

- `feature/player-movement`
- `feature/enemy-spawning`
- `feature/auto-cannon`
- `art/player-boat`
- `fix/player-damage`

## While Working

Commit changes in reasonable checkpoints with clear messages.

Examples:

- `Add basic player movement`
- `Add enemy spawn timer`
- `Fix diagonal movement speed`

Avoid developing directly on `main`.

## When Finished

1. Push your branch to GitHub.
2. Open a Pull Request into `main`.
3. Complete the Pull Request template.
4. Link the related Issue using `Closes #`.
5. Move the Issue to `Review`.

After the Pull Request is tested and merged, move the Issue to `Done`.
